# Данные мест Астаны

`places.json` — настоящий локальный снимок OpenStreetMap, полученный автоматизированным запросом OSM (точный endpoint в provenance.json). Точное время получения, версия базы, endpoint, количество записей и запрос находятся в `provenance.json`. Это сведения участников OSM, а не проверка на месте и не официальная гарантия заведения.

## Воспроизводимый сбор

```sh
node scripts/collect.mjs
# Альтернативный публичный endpoint:
OVERPASS_URL=https://overpass-api.de/api/interpreter node scripts/collect.mjs
```

Требуется Node 20+ и сеть. Один ограниченный запрос охватывает район EXPO / Mega Silk Way рядом с NU, фильтрует именованные кафе, библиотеки, парки, музеи, достопримечательности и торговые центры. Нет обхода блокировок, авторизации или массового скрейпинга. При ошибке старый снимок не перезаписывается. Не запускайте сборщик в цикле или на каждый запрос пользователя; снимок предназначен для локального поиска.

Для окружения с системным proxy допустимо получить тот же запрос через curl, затем нормализовать ответ:

```sh
curl --fail --max-time 120 --data-urlencode data@data/query.overpassql https://overpass.private.coffee/api/interpreter -o /tmp/astana-overpass.json
node scripts/collect.mjs /tmp/astana-overpass.json
```

## Схема

Массив объектов: `id`, `name`, `lat`, `lon`, `category`, исходные `tags`, `description`, `descriptionType`, `sourceUrl`, `fetchedAt`, `openingHours` (строка OSM или null). Категории: cafe, park, museum, mall, attraction, library. Названия сохранены из источника без выдуманного перевода. `name:kk`, `name:ru`, `name:en`, если есть, остаются внутри tags.

Описания явно производные: только имя и категория, без добавления фактов. Координаты площадных объектов — центры bounding box, не входы. Записи с access=no/private/customers/permit/military и disused/abandoned=yes отбрасываются. Отсутствие access не гарантирует открытый вход: уточните условия перед визитом. Неполнота OSM может затронуть кафе в кампусе, торговых центрах и часы работы.

Часы не означают «открыто сейчас»: нужен корректный интерпретатор opening_hours с часовым поясом Asia/Almaty. Тишина, розетки, цены и доступность не выводятся из категории. Расстояния и длительности, вычисленные приложением, являются оценками, а не данными OSM и не пешеходными маршрутами.

## Фактическая проверка сбора

19 октября 2026: основной Overpass endpoint вернул HTTP 502/406, Kumi не ответил в срок. Зеркало private.coffee успешно вернуло реальные POI. Поэтому оно выбрано endpoint по умолчанию для воспроизводимого обновления. Для демо оставлен успешно собранный компактный снимок официального OSM API: 13 POI района EXPO/Mega, получены 2026-10-19 в 17:39:20 UTC. Контрольный повтор узкого запроса Overpass завершился таймаутом и не перезаписал снимок. Точные сведения записаны в provenance.json. В ходе диагностики также успешно проверен официальный OSM API, но его [политика](https://operations.osmfoundation.org/policies/api/) рекомендует Overpass для read-only задач: сборщик использует именно Overpass.

Кампусные NU Park и Kunde Cafe консервативно исключаются: публичный доступ не проверен. Дублирующий узел Mega исключается в пользу полигона. Из-за полных пересекающихся полигонов центр ботанического сада может лежать чуть за bbox. Все записи имеют идентификатор и ссылку на исходный объект.
