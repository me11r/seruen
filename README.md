# Seruen · Bulan

Готовый локальный MVP первого кейса Build with AI: персональные короткие прогулки по Астане. «Серуен» означает прогулку. Казахский интерфейс по умолчанию, русский и английский переключаются полностью. Без регистрации.

## Быстрый запуск

Требуется Node.js **22.16+**, npm и интернет для подложки карты. Сервер и поиск работают без интернета после установки.

```bash
npm ci
cp .env.example .env
npm run build
npm start
```

Открыть **http://localhost:3000**, приложение — **http://localhost:3000/#app**. `npm run dev` запускает тот же сервер; после изменения серверных файлов перезапустите его. `npm run build` копирует локальный Leaflet и собирает переносимый каталог `dist/`. В `dist` нет секретов. Запуск сборки: `node --env-file-if-exists=.env dist/server.mjs`.

## Настройка модели

В `.env` установите `OPENAI_API_KEY` и при необходимости `OPENAI_MODEL` (по умолчанию `gpt-4.1-mini`, нужна доступность модели в вашем аккаунте и поддержка Responses API со structured outputs). Затем перезапустите сервер. Ключ используется только в серверном Authorization-заголовке. `.env` исключён из Git; сервер не отдаёт его через HTTP. `store:false` отключает сохранение response как объекта в OpenAI API, но не является обещанием отсутствия всех служебных журналов у провайдера.

Без ключа: реальный локальный поиск + переведённые шаблонные объяснения, заметная метка «Демо · без AI-генерации». С ключом: найденные записи передаются в Responses API; модель возвращает 1–3 ID и идеи. Все ID проверяются повторно сервером. При ошибке API или timeout — реальные результаты поиска с предупреждением и кнопкой повтора. Не выдаём fallback за ответ живой модели.

**Живой OpenAI и 2GIS не проверены с реальными ключами:** ключи не предоставлялись. Контракт OpenAI, обработка сбоя и отклонение неизвестных ID проверены на mock-ответах.

## Демо за 2 минуты

1. Открыть приложение, оставить EXPO, нажать пример прогулки на 60 минут.
2. Открыть источник первой карточки, показать реальную OSM-запись и дату сбора.
3. Нажать «На карте»: номер совпадает с карточкой. Нажать другой маркер.
4. Уточнить «Осталось 30 минут», затем «Ближе».
5. Сбросить фильтры, выбрать MEGA Silk Way, запросить кофе и учёбу на 60 минут.
6. Переключить ҚАЗ / РУС / ENG. Названия из OSM не переводятся искусственно.
7. Показать строгий фильтр бесплатности: при отсутствии `fee=no` приложение честно сообщает об отсутствии подходящих записей.

## Данные и сбор

`npm run collect` — воспроизводимый сетевой сбор. Точный источник, запросы, область, исходные данные и время — в [data/README.md](data/README.md), [data/provenance.json](data/provenance.json). Локальный снимок: `data/places.json`; полный набор доступен также по `/api/dataset`. Обновляйте данные заранее, не во время защиты: публичные источники могут быть недоступны. После обновления перезапустите сервер и повторите тесты. Данные © OpenStreetMap contributors, ODbL 1.0. Код не заменяет лицензию исходных данных.

Описания производны от тегов и не добавляют фактов. Координаты площадных объектов могут быть центрами геометрии, а не входами. Мы не заявляем полное покрытие Астаны, не подтверждаем наличие розеток/тишины/доступной среды и не вычисляем «открыто сейчас» по неполным данным.

## Как работает поиск и RAG

`lib/search.mjs`: мультиязычные правила извлекают временные/категорийные ограничения, продолжение сохраняет структурированный контекст. BM25-подобное лексическое ранжирование по реальным названиям/тегам плюс географический приоритет. Строгие фильтры применяются до генерации. Это retrieval без embeddings — векторная база не обязательна для RAG. Найденные top-6 записей передаются в `lib/model.mjs`; генерация ссылается только на их ID. Карточки получают координаты и источник с сервера, а не от модели. Подробнее — [docs/RAG.md](docs/RAG.md).

Время = расстояние по прямой × 1,35 / 4,5 км/ч, округление вверх, дорога туда-обратно + 15–35 минут на месте. Коэффициент эвристический, не оценка качества дорожной сети. Заборы, переходы, погода и входы не учитываются. Карточки — альтернативы, не последовательность общего маршрута.

## Карта

- По умолчанию Leaflet 1.9.4 с тайлами OpenStreetMap. Библиотека поставляется локально после build; тайлы требуют сети. Атрибуция показана, массовая загрузка/предзагрузка и offline-кэш тайлов не используются.
- Для 2GIS задайте **TWOGIS_MAP_KEY**: публичный браузерный ключ сервиса **MapGL JS API**. Ограничьте допустимые домены в кабинете. Он закономерно виден браузеру и не является OpenAI-секретом.
- **Places/Search API и Directions API не используются и не входят автоматически в доступ к карте.** Для будущего поиска организаций/маршрутизации потребуются соответствующие подключённые сервисы и отдельная серверная конфигурация. В MVP таких переменных нет.
- При ошибке 2GIS подключается Leaflet; при сбое тайлов список и чат остаются доступны. Нет нарисованных линий, выдаваемых за пешеходный маршрут. Внешняя ссылка открывает координаты места в 2GIS.
- [MapGL setup](https://docs.2gis.com/en/mapgl/start/first-steps), [Markers](https://docs.2gis.com/en/mapgl/objects/markers), [Directions](https://docs.2gis.com/en/api/navigation/directions/overview), [OSM tile policy](https://operations.osmfoundation.org/policies/tiles/).

## Эксперимент: ветер и маршрут

Открыть **http://localhost:3000/#wind**. Независим от OpenAI-ключа. По умолчанию явно помеченные моделируемые условия; отдельная кнопка «Реальная погода» получает общий прогноз Open-Meteo. Реальная ошибка не заменяется демоданными.

Используется связный граф OSM EXPO: 1852 узла, 2026 сегментов, 277 исходных дорожек. Нет выдуманных связей. Сравниваются реальные кандидатные пути, с ограничением обхода и полным учётом возвращения. Нет моделирования зданий, температуры или охлаждения. Подробности, формула и ограничения: [docs/WIND.md](docs/WIND.md). Обновление сети: `python3 scripts/collect-paths.py` (Python 3, стандартная библиотека; сеть Overpass).
