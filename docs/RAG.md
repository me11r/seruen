# RAG для жюри

Seruen решает вопрос «куда сходить за мой свободный час рядом со мной». Данные о местах не берутся из памяти модели.

1. **Сбор:** автоматизированный запрос открытых OSM-данных, извлечение именованных POI, фильтрация ограниченного доступа, сохранение ID, координат, категории, тегов, ссылки и даты. Датасет хранится локально для стабильного демо.
2. **Запрос:** позиция и фильтры остаются в памяти текущей вкладки. Мультиязычные правила извлекают время, категорию, бюджет и пожелание помещения. Уточнение сохраняет предыдущие ограничения.
3. **Retrieval:** рассчитывается расстояние, отбрасываются места вне временного бюджета и категории; лексическая релевантность BM25 плюс близость ранжируют кандидатов. До шести реальных записей формируют контекст.
4. **Generation:** OpenAI Responses API получает только запрос, ограничения и найденные POI. JSON Schema ограничивает идентификаторы этим набором. Модель формулирует мотивацию и идею занятия на выбранном языке.
5. **Проверка:** сервер отклоняет неизвестные и повторные ID. Все фактические поля карточки заполняются из датасета. Источник, дата, время-оценка и сгенерированная идея разделены.

Без ключа этап 4 заменён явно обозначенным шаблоном; это демонстрация retrieval, не демонстрация живой генерации. При недоступности API показано отдельное предупреждение.

Почему не vector database: на небольшом датасете география и строгие ограничения важнее дополнительной инфраструктуры. Лексический retrieval — настоящий retrieval; схема становится RAG при подключении генерации. Ограничение: синонимы и сложные отрицания вне правил могут распознаваться плохо. Следующий эксперимент — сравнить текущий поиск с multilingual embeddings на размеченных запросах, измеряя попадание подходящего места в top-3.

Модель не является фактчекером: schema предотвращает вымышленные ID, но не доказывает истинность каждого предложения. Инструкция запрещает новые факты; перед публичным масштабированием нужен набор оценок unsupported claims и дополнительная проверка текста. В MVP не заявляются «открыто сейчас», рейтинги и события.

Основа интеграции: https://developers.openai.com/api/docs/guides/structured-outputs (проверено 19.10.2026).
