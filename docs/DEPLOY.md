# Публикация Seruen

Сайт ещё не опубликован. Самый простой вариант — любой Node.js/Docker-хостинг с HTTPS, переменными окружения и исходящим доступом к OpenAI. Не требуется GCP.

## Node.js

1. Создайте свой репозиторий, исключив `.env`, `node_modules`, временные файлы. Включите `data/places.json`, происхождение и лицензионную заметку.
2. На сервере Node 22: `npm ci && npm run build`.
3. Установите секрет `OPENAI_API_KEY` в панели хостинга, модель `OPENAI_MODEL=gpt-4.1-mini`. Для демо можно оставить ключ пустым.
4. Команда запуска: `npm start`. Порт задаётся `PORT`; health check: `/api/health`.
5. Привяжите HTTPS-домен. Геолокация работает на localhost или HTTPS. Для 2GIS включите MapGL и укажите домен в ограничениях ключа.
6. Проверьте KZ/RU/EN, 3 сценария, отсутствие `.env` по URL, сбой модели и мобильный браузер. Запишите URL в материалы сдачи.

## Docker

```bash
docker build -t seruen .
docker run --rm -p 3000:3000 --env-file .env seruen
```

На публичном сервере ставьте контейнер за reverse proxy с TLS. Не включайте тела запросов в access-логи, отключите сбор геолокации аналитикой. Настройте upstream rate limiting, лимиты расходов/проектный ключ OpenAI. MVP не является готовым многопользовательским production-сервисом: нет устойчивого распределённого rate limiter, мониторинга и SLA. Для большого трафика выберите коммерческий/собственный tile provider согласно условиям использования.

## Перед записью

Обновите датасет отдельно и проверьте его до демо; во время защиты используйте локальный снимок. Если ключ не сработал, не скрывайте fallback-метку. Сохраните запись экрана и отдельно загрузите в YouTube с доступом по ссылке. Создание аккаунтов и публикация этим проектом автоматически не выполняются.
