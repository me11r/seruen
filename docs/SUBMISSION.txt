ЗАПУСК ПРОТОТИПА
Node.js 22 или новее:
npm ci
npm run build
npm start
Открыть http://localhost:3000
Ветровой эксперимент: http://localhost:3000/#wind

Без ключей работает явно обозначенный деморежим с реальным поиском.
Для живой генерации скопировать .env.example в .env, указать свой
OPENAI_API_KEY с доступным балансом; TWOGIS_MAP_KEY необязателен.
Реальные ключи в архив не включены.
