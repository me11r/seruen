# Реализовано и оставшиеся ограничения

## Реализовано

- Лендинг и приложение Seruen от Bulan; корректная независимость от NU.
- Казахский по умолчанию, полные RU/EN словари и переключение рекомендаций; сохранение только языка.
- Начальная точка: EXPO, MEGA, внешний ориентир NU, клик карты, геолокация по кнопке.
- Время, интерес, помещение, бюджет; свободный запрос и продолжение с контекстом.
- Реальный локальный retrieval, географические ограничения, 1–3 карточки с источниками и датой.
- Серверный OpenAI Responses RAG со structured outputs, настраиваемая модель, проверка ID, timeout и честный fallback.
- Демонстрационный режим без секретов: поиск реальный, объяснения шаблонные.
- Leaflet/OpenStreetMap, опциональный 2GIS MapGL, нумерация, выделение, масштаб, возврат, деградация без карты.
- Автоматизированный сбор; успешный реальный снимок 13 POI, ODbL, происхождение, повторный сбор Overpass.
- Десять слайдов в HTML/PDF, речь, сценарий видео, README, Dockerfile и инструкции публикации.
- Проверки поиска, DOM и HTTP выполнены; PDF визуально просмотрен.

## Ограничения

Снимок охватывает небольшой район EXPO/MEGA, не всю Астану; музеев в текущей выборке нет, поэтому музейный фильтр честно может дать пустой результат. Нет событий, рейтингов, актуальных цен или «открыто сейчас». Сбор Overpass в среде нестабилен: финальный успешный снимок получен официальным OSM API, это явно записано в provenance.

Бюджет «экономно» — приоритет парков, не доказательство низкой цены. «Бесплатно» допускает только fee=no. «В помещении» определяется по категориям, не обследованием здания. Тишина, розетки, доступная среда и безопасность не гарантируются. В основном поиске мест время эвристическое, без дорожного графа; центры площадных объектов не обязательно являются входами.

Мультиязычный разбор ограничений основан на правилах и не понимает все сложные пожелания/отрицания. Лексический поиск не заменяет полноценную семантическую оценку. Генерация может ошибаться в тексте даже при правильном ID; нужен eval на неподтверждённые утверждения перед массовым выпуском.

Живые OpenAI/2GIS и реальная мобильная вёрстка требуют контрольного прогона пользователем: ключи не предоставлялись, browser automation недоступен. DOM-проверки не выданы за визуальный тест. Сайт/репозиторий не опубликованы, видео не записано и не загружено.

## Перед демонстрацией

1. `npm ci && npm run build`, `cp .env.example .env` (если файла ещё нет), добавить ключ и `npm start`.
2. Пройти ручной список из TESTS.md; если ключа нет, презентовать честный demo-режим.
3. Открыть PDF, приложение и текст выступления; сохранить локальный снимок для стабильного показа.
4. Самостоятельно опубликовать проект/архив, записать и загрузить видео по VIDEO.md, добавить реальные ссылки в заявку.

## Добавление: эксперимент ветра

Добавлен отдельный режим `/#wind`: реальный OSM-граф EXPO, два варианта пути, моделируемый ветер, отдельное получение Open-Meteo, подсветка встречного ветра, ограничения обхода и полный расчёт возвращения. Живой погодный запрос и HTTP-сценарий прошли. Это ограниченная геометрическая маршрутизация; основной поиск мест по-прежнему показывает приблизительное время, не маршруты из этого графа.

Лендинг: удалены декоративные значки, подключён локальный Noto Sans с более насыщенной типографикой. Добавлены авторы Tazdarbay Meiirzhan и Mukhamejanov Aidos.
