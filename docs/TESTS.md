## Что НЕ отмечено как проверенное

- Живой OpenAI Responses API с вашим ключом и доступной моделью.
- 2GIS MapGL с вашим ключом, его разрешённым доменом, WebGL и реальным отказом авторизации.
- Тайлы OSM, реальные клики и внешний переход в полноценном браузере.
- Геолокация физического устройства, клавиатура телефона, контраст инструментальным анализатором, экранный диктор.
- Deploy на внешнем хостинге и Docker build (Dockerfile подготовлен, сборка контейнера не запускалась).

В этой сессии browser automation вернул `Browser is not available` для Chrome и встроенного браузера. DOM-тесты проверяют обработчики и состояния, но не рисование карты и адаптивные размеры. PDF отрендерен отдельным headless-процессом как документ; это не проверка приложения в живом браузере.

## Ручной прогон перед защитой (5 минут)

1. Запустить localhost:3000/#app в Chrome. Проверить, что карта загрузилась, атрибуция видна, нажатие карты меняет начальную точку.
2. Пройти EXPO 60 → 30 минут; выбрать карточку и маркер. Убедиться, что нумерация совпадает.
3. MEGA → кофе; раскрыть источник. Проверить внешнюю ссылку 2GIS.
4. Сменить все языки, перезагрузить вкладку: язык должен сохраниться, история — сброситься.
5. Отклонить запрос геолокации; затем выбрать preset. Отключить сеть: список существующих рекомендаций остаётся, новый запрос показывает ошибку.
6. Проверить ширины 390×844 и 1440×900, масштаб 200%, Tab/Enter, контраст и поле ввода при открытой клавиатуре.
7. Добавить ключ OpenAI, перезапустить. Успешный запрос должен иметь `mode: live`; ошибка ключа должна дать `mode: fallback`, не скрытый успех.
8. При наличии ключа 2GIS повторить карту. Без ключа оставить Leaflet для демо.

Скрипт smoke запускается только после сервера. В sandbox потребовалось разрешение на локальные соединения; это ограничение среды проверки, а не приложения.

## Повторная диагностика с настроенными ключами · 19.10.2026

Оба ключа читаются из `.env`. Запущенный сервер отдаёт режим live и актуальный публичный ключ карты. Реальный запрос через адаптер OpenAI получил HTTP 429: `insufficient_quota`, `credit_balance_exhausted`; успешная генерация пока не подтверждена. Официальный endpoint ключей 2GIS для `mapgl-js-api` вернул HTTP 200, meta.code=200 и is_active=true. Это проверка активности сервиса, не визуальный тест карты.

В приложении теперь отдельно отображаются ошибки баланса/квоты, авторизации и лимита запросов OpenAI на трёх языках. Добавлены тесты этих кодов; тесты и сборка прошли. Для загрузки изменённой серверной логики нужен перезапуск процесса.
